# FormPilot Pro 10.21.0

## Repeatable Groups + True Drag-and-Drop Form Builder

- Added **Repeater / Repeatable Group** field.
- Repeaters support configurable minimum, maximum, and default item counts.
- Configurable item label, Add button text, and Remove button text.
- Repeatable child fields support common field types and required flags.
- Added inline child-field editing and sortable child-field order in the builder.
- Frontend repeaters add/remove rows without page reloads and preserve existing values.
- Backend validates repeater row counts and required child values before saving.
- Repeater values are stored as structured arrays in entries, making work history, education, references, certifications, projects, etc. usable as structured data.
- Added repeatable Work Experience and Education History to the Job Application multi-step template.
- Added true drag-and-drop from the field palette into the exact position in the form canvas.
- Existing canvas fields remain sortable by drag handle.
- Submit Button remains pinned as the final action and cannot be duplicated/deleted.
- Added drag/drop placeholder and insertion feedback.
- Existing click-to-add behavior remains available.

## Compatibility

- Existing forms continue to work without repeaters.
- Existing multi-step forms continue to use Page Break fields.
- No License Manager changes are required.
