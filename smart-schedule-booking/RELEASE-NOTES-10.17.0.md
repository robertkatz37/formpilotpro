# FormPilot Pro 10.17.0

## Multi-Step Form UI/Styling
- Fixed progress display so Percentage Bar mode renders as a clean progress bar instead of overlapping with the numbered step indicator.
- Added per-form Multi-Step Design settings: progress color, track color, connector color, active/completed/inactive step colors, step text color, shape, indicator size, bar height, spacing, percentage/step labels, step titles, completed-step clickability, and transition animation.
- Settings are sanitized server-side and applied only to the selected form.
- Completed-step navigation can be disabled independently of Previous buttons.
- Added responsive styling for mobile layouts.
